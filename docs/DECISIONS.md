| 2026-10-07 | A message whose classification fails is held in an in-memory buffer and retried, not dropped. | 2026-10-07 | A held message is dropped after PENDING_MAX_ATTEMPTS and logged as `pending_dropped_unclassified stored=false` | An unbounded retry would grow the buffer during a long outage and silently imply the message is still coming | src/core/tuning.ts, src/bots/shared/pending.ts |
